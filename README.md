# homebrew-dcctl

Homebrew tap for [dcctl](https://github.com/hrodrig/dcctl) — Docker Compose Control. CLI to manage Docker Compose stacks per environment using a single YAML config file.

## Install

```bash
brew install hrodrig/dcctl/dcctl
```

## Links

- **Project:** [github.com/hrodrig/dcctl](https://github.com/hrodrig/dcctl)
- **Releases:** [dcctl releases](https://github.com/hrodrig/dcctl/releases)

The cask is updated automatically on each dcctl release (GoReleaser).
